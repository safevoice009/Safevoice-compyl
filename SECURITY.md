# Security Policy

## Reporting a Vulnerability

The project team and community take all security bugs in this project seriously. We appreciate your efforts and responsible disclosure and will make every effort to acknowledge your contributions.

To report a security vulnerability, please create a GitHub issue in the project's repository. Please provide a detailed description of the vulnerability, including steps to reproduce it.

Our security team will acknowledge the issue within 48 hours and will work to validate the report. We will keep you informed of our progress toward a fix and will notify you when the vulnerability has been patched.
